## Дипломный проект 

### Проект для автоматизации тестирования с помощью Python.
Тесты созданы на основе тестов из курсовой работы - [Финальный проект по ручному тестированию](https://dz11-mal.yonote.ru/share/268e5852-9a19-4e7d-8ab2-f7f32fdda212).

Всего было составно 5 тестов по функциональному чек-листу и 5 API тестов на основе коллекции и кейсов.

В тестах используются переменные окружения: URL для функциональных тестов, API_URL для тестов api, а так же TOKEN для тестов api. 

TOKEN берем из DevTools - Application - Cookies - access-token. Токен имеет срок годности. 


### Необходимые библиотеки:
```
pytest
selenium
requests
allure-pytest
```

###  Установка и настройка:
1. Установите репозиторий:
git clone  [GitHub](https://github.com/Roscoet12/KsMal-diploma.git)
2. Откройте проект в PyCharm
3. Установите необходимые библиотеки:
```
pip install -r requirements.txt 
```

###  Для запуска всех тестов используйте команду:
```
pytest
```

###  Для запуска ui тестов используйте команду:
```
pytest -m "ui_test"
```

###  Для запуска api тестов используйте команду:
```
pytest -m "api_test"
```
###  Для генерации результатов тестов с помощью allure используйте команду:
```
python -m pytest --alluredir allure-result
```

###  Для конвертации результатов тестов в отчет с помощью allure используйте команду:
```
allure serve allure-result
```
